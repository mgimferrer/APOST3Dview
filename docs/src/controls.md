# Mouse and keyboard

## In the view

| To | Do |
|---|---|
| Rotate | Drag (either mouse button, or the trackpad) |
| Pan | <kbd>Shift</kbd>+drag |
| Zoom | Scroll over the molecule, or pinch on a trackpad (scrolling over a window only scrolls the window) |
| Rotate with the keyboard | Arrow keys; two at once for a diagonal |
| Turn continuously | <kbd>Space</kbd> (again to stop), in the direction of the last arrow key pressed |
| Select an atom or a bond | Click it; click again to take it out of the selection |
| Select many atoms | <kbd>Alt</kbd>+drag a box around them (<kbd>Option</kbd>+drag on a Mac) |
| Clear the selection | <kbd>Esc</kbd> |
| See pair values from another atom or fragment | Click it, while a pair quantity is shown |
| Move a measurement's label | Drag it |
| Previous or next frame (a structure with [frames](frames.md)) | <kbd>,</kbd> or <kbd>.</kbd> |

The arrow keys, <kbd>Space</kbd>, <kbd>,</kbd> and <kbd>.</kbd> do nothing while you are typing in a text field.

## While the Build window is open

Only while the [Build window](building.md) is open. Closing it gives every key and drag back its usual meaning.

| To | Do |
|---|---|
| Undo the last edit | <kbd>Cmd</kbd>+<kbd>Z</kbd> (<kbd>Ctrl</kbd>+<kbd>Z</kbd>), or **Undo** |
| Redo | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>), or **Redo** |
| Delete the selected atoms | <kbd>Delete</kbd> (or <kbd>Backspace</kbd>), or **Delete selected atoms** |
| Set a distance, angle or dihedral | Select 2, 3 or 4 atoms, type the value, <kbd>Enter</kbd> or **Set** |
| Switch dragging atoms on or off | <kbd>D</kbd>, or **Drag atoms (D)** (off whenever the Build window opens) |

With **Drag atoms (D)** on:

| To | Do |
|---|---|
| Move atoms in the plane of the screen | Drag from an atom |
| Turn them about their center | <kbd>Cmd</kbd>+drag (<kbd>Ctrl</kbd>+drag) from an atom |
| Move them toward you or away | <kbd>Shift</kbd>+drag up or down from an atom |
| Rotate the view | Drag from empty space (as always) |
| Undo a drag while dragging | <kbd>Esc</kbd> before releasing |
| Choose what a drag moves | **Drag moves:** **The atom (or the selection)** or **Its piece** |

These keys do nothing while you are typing in a text field.

## Anywhere

| To | Do |
|---|---|
| Open files | <kbd>Cmd</kbd>+<kbd>O</kbd> (<kbd>Ctrl</kbd>+<kbd>O</kbd> on Windows and Linux), or drag them onto the window |
| Save the session | <kbd>Cmd</kbd>+<kbd>S</kbd> (<kbd>Ctrl</kbd>+<kbd>S</kbd>) |
| Add a fragment to the selection (Fragments list) | <kbd>Cmd</kbd>-click (<kbd>Ctrl</kbd>-click) |
