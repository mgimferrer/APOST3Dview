# Mouse and keyboard

## In the view

| To | Do |
|---|---|
| Rotate | Drag (either mouse button, or the trackpad) |
| Pan | <kbd>Shift</kbd>+drag |
| Zoom | Scroll, or pinch on a trackpad |
| Rotate with the keyboard | Arrow keys; two at once for a diagonal |
| Turn continuously | <kbd>Space</kbd> (again to stop), in the direction of the last arrow key pressed |
| Select an atom or a bond | Click it; click again to take it out of the selection |
| Select many atoms | <kbd>Alt</kbd>+drag a box around them (<kbd>Option</kbd>+drag on a Mac) |
| Clear the selection | <kbd>Esc</kbd> |
| See pair values from another atom or fragment | Click it, while a pair quantity is shown |
| Move a measurement's label | Drag it |

The arrow keys and <kbd>Space</kbd> do nothing while you are typing in a text field.

## Anywhere

| To | Do |
|---|---|
| Open files | <kbd>Cmd</kbd>+<kbd>O</kbd> (<kbd>Ctrl</kbd>+<kbd>O</kbd> on Windows and Linux), or drag them onto the window |
| Save the session | <kbd>Cmd</kbd>+<kbd>S</kbd> (<kbd>Ctrl</kbd>+<kbd>S</kbd>) |
| Add a fragment to the selection (Fragments list) | <kbd>Cmd</kbd>-click (<kbd>Ctrl</kbd>-click) |
