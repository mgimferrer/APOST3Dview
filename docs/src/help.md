# Getting help

## Reporting a problem or suggesting a feature

Please open an issue on GitHub: [github.com/mgimferrer/APOST3Dview/issues](https://github.com/mgimferrer/APOST3Dview/issues/new/choose). There are forms for a problem report and for a suggestion. For a problem, the **About** window's **Copy these details** button copies the version, your system and your graphics card, to paste into the report, and the log file helps too (see [Troubleshooting](troubleshooting.md)).

You can also write to Martí Gimferrer, [mgimferrer18@gmail.com](mailto:mgimferrer18@gmail.com).

## APOST-3D

Questions about APOST-3D itself (its analyses, its keywords, its results) are answered in [APOST-3D's repository and documentation](https://github.com/mgimferrer/APOST3D).

## Building from source

For development, or if a download doesn't work on your system, APOST3Dview can be built from its source code: see [BUILDING.md](https://github.com/mgimferrer/APOST3Dview/blob/main/BUILDING.md) in the repository.
